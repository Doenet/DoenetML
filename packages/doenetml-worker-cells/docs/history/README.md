# History

How the prototype got here, round by round. Each round started from a brief
(`instructions*.md`; the first round's is `instructions.md`, there was no
brief for round 4) and recorded its scope and decisions in `plan-N.md`. The
measurements and verdicts are in `RESULTS.md` and `results/NOTES.md`; lasting
design decisions are in `docs/adr/`.

These files describe the code as it was when each round ran. Paths and names
in them may since have moved; `ARCHITECTURE.md` describes the code as it is.
