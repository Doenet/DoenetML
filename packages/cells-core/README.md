# @doenet/cells-core

A DoenetML core organized around a flat list of `f64` cells: components and
props name cells, and the dependency graph is a list of operators with
inverses. `ARCHITECTURE.md` is the map, `CONTEXT.md` the vocabulary,
`docs/adr/` the decisions.

- `crates/cells-core`: the core, with math-expressions-rs as its symbolic
  engine (`src/sym/`, ADR 0011).
- `crates/cells-wasm`: the browser binding; `npm run build:rust` puts it in `pkg/`.
- `crates/cells-docgen`: synthetic DoenetML for the fixtures and benches.
- `crates/cells-bench`: benches, `stats`, and the `golden`, `regress` and
  `sir_perf` examples.
- `scripts/`: the parser wrapper (`parse-dast.mjs`), the binary encoder
  (`cdast-encode.mjs`), fixture generation and the refactoring guards.
- `fixtures/`: generated by `npm run fixtures`; only `sir.doenet` is
  hand-written and committed.

Tags the core understands: `document`, `graph`, `point`, `number`,
`numberInput`, `booleanInput`, `slider` (numeric mode), `math`, `evaluate`,
`repeatForSequence`, `collect`, `line`, `lineSegment`, `circle`, `polygon`
(and `triangle`), `pointList`, `p`, `setup`, `stickyGroup`, `mathInput`,
`function`, `derivative`, `answer`, `conditionalContent` (`case`, `else`),
`select` (`option`), `group` (and `label`), literal `text`, the sections
(`section`, `subsection`, `subsubsection`, `problem`, `exercise`, `example`),
`functionIterates`, `repeat` (over a function's iterates), `clampNumber`,
`polyline`, `triggerSet` and `updateValue`, the text and layout containers
`title`, `ref`, `ul`, `li`, `m`, `md`, `mrow`, `aside`, `sideBySide`,
`stack`, `tabular`, `spreadsheet`, `row`, `cell` and `legend`. With the
`testing` feature (on under `cargo test`), also `op`, which names an
operator directly. A `<math>` tuple of three or more entries is a tuple
(`$t[2]`); a function of several variables or with a tuple value is only
iterated. `fixtures/sir.doenet` is a document using most of these.

Scripts: `npm test` (builds `@doenet/parser`, then `cargo test --workspace`;
needs `node`), `npm run lint` (fmt and clippy, warnings denied),
`npm run fixtures`, `npm run bench`, `npm run golden-diff -- [rev]`,
`npm run perf-diff -- [rev]`.
