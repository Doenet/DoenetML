# `<md>{:dn}`

<ComponentDisplay name='md'/>

`<md>{:dn}` is a [Display Math](../concepts/essentialConcepts#component-types)
component that renders a block of aligned display mathematics when used in combination 
with the `<mrow>{:dn}` component.

<AttrPropDisplay name='md'/>
 
## Examples

### Example: `<md>{:dn}` with nested `<mrow>{:dn}` children


```doenet-editor-horiz
<p>The trigonometric ratios for the angle <m>\theta = \pi/2</m>:
  <md>
    <mrow>\sin(\theta) &= 1</mrow>
    <mrow>\cos(\theta) &= 0</mrow>
    <mrow>\tan(\theta) &= \text{undefined}</mrow>
  </md>
</p>  
```



The data contained within an `<md>{:dn}` block must be contained in 
an [`<mrow>{:dn}`](mrow.mdx).  Equations and content will align vertically where 
the `&` symbol is entered in each row. 



---

### Example: `<md>{:dn}` cannot contain `<answer>{:dn}`


```doenet-editor-horiz
<p>The following will not render as intended:</p>
<md>
  <mrow>x = <answer name="ans1"><label>What is x?</label>x</answer></mrow>
</md>
```



An `<md>{:dn}` block cannot contain an `<answer>{:dn}`. An input on its own can
be written into a row, though, and an `<answer>{:dn}` outside the display can
check it — see the next example.



---

### Example: an input inside `<md>{:dn}`, checked by an `<answer>{:dn}` outside


```doenet-editor-horiz
<md>
  <mrow>2x + 1 &= 7</mrow>
  <mrow>x &= <mathInput name="x" /></mrow>
</md>
<p><answer><award><when>$x = 3</when></award></answer></p>
```



The input is drawn inside the aligned display where it was written, and the
`<answer>{:dn}` refers to it by name and checks what was entered. The input
needs no `<shortDescription>{:dn}`: its own row describes it to a screen
reader, as "x = blank".



---

### Example: filling in a step of a derivation


```doenet-editor-horiz
<md>
  <mrow>f(x) &= x^2 + 2x</mrow>
  <mrow>f'(x) &= <mathInput name="step">
    <shortDescription>the derivative of f</shortDescription>
  </mathInput></mrow>
  <mrow>f''(x) &= 2</mrow>
</md>
```


A `<textInput/>{:dn}`, a `<mathInput/>{:dn}`, or an inline
`<choiceInput/>{:dn}` written inside an `<mrow>{:dn}` is rendered *in place*,
inside the aligned display, so the reader completes the missing step where it
belongs, and the rows stay aligned at the `&` around it. Use a
`<mathInput/>{:dn}` when the missing step is mathematics the reader should
write as mathematics; the display makes room for it as it grows, and closes
back up as it shrinks.

Without a `<shortDescription>{:dn}`, the input is described to a screen reader
by its own row alone — here, "f'(x) = blank" — not by the whole display, so no
accessibility violation is reported. In this example, the
`<shortDescription>{:dn}` given replaces that default.

The same restrictions apply as inside `<m>{:dn}`: a non-`inline`
`<choiceInput/>{:dn}`, an `expanded` `<textInput/>{:dn}` or one given a
relative width (in `%` or `em`), and any input in a display drawn on a
`<graph>{:dn}` cannot be placed inside the display. Those inputs are not
shown, and a warning explains the problem.



---

### Example: `<md>{:dn}` with referenced `<math>{:dn}`


```doenet-example
<p><m>f(x) = <function name="f" variables="x">x^2</function></m></p>
<p><m>g(y) = <function name="g" variables="y">sqrt(y)</function></m></p>
<p><m>h(z) = <function name="h" variables="z">sin(z)</function></m></p>

<p>The first derivatives of functions <m>f(x)</m>, <m>g(y)</m> and <m>h(z)</m> are:
  <md>
    <mrow>\frac{df}{dx} &= 
      <derivative derivVariables="x">$f</derivative>
    </mrow>
    <mrow>\frac{dg}{dy} &= 
      <derivative derivVariables="y">$g</derivative>
    </mrow>
    <mrow>\frac{dh}{dz} &= 
      <derivative derivVariables="z">$h</derivative>
    </mrow>    
  </md>
</p>  
```



Computational DoenetML components, such as `<math>{:dn}`, or `<derivative>{:dn}`, can be nested within or 
referenced within an `<md>{:dn}` block.


Exceptions: The `<answer>{:dn}` component and other `<md>{:dn}` components 
cannot be nested within an `<md>{:dn}` block.



---

### Example: `<md>{:dn}` on a `<graph>{:dn}`


```doenet-editor-horiz
<graph><shortDescription>A graph of two lines and their intersection</shortDescription>
  <line name="line1">2x - y = 3</line>
  <line name="line2">x + y = 5</line>
  <intersection>$line1 $line2</intersection>

<md anchor="(-6,4)">
  <mrow>$line1.equation</mrow>
  <mrow>$line2.equation</mrow>
</md>
</graph>
```



An `<md>{:dn}` block can be placed on a `<graph>{:dn}`. The `anchor` attribute 
can be used to specify its initial location.



## Attribute Examples

### Attribute Example: Standard graphical attributes


```doenet-editor-horiz
<p>
  <booleanInput name="hideEq"><label>Hide equations</label></booleanInput> $hideEq</p>
<p>
  <booleanInput name="canDrag" prefill="true"><label>Drag equations</label></booleanInput> $canDrag</p>
<graph><shortDescription>A graph of two lines and their intersection</shortDescription>
  <line name="line1">2x - y = 3</line>
  <line name="line2">x + y = 5</line>
  <intersection>$line1 $line2</intersection>
<md 
  name="eqBlock" 
  anchor="(-6,4)" 
  draggable="$canDrag" 
  hide="$hideEq"
  styleNumber="2">
    <mrow>$line1.equation</mrow>
    <mrow>$line2.equation</mrow>
</md>
</graph>     
```



Since an `<md>{:dn}` block can be placed on a graph, the standard graphical 
attributes `draggable`, `hide`, and `styleNumber` can be used to control its appearance and behavior.



## Property Examples

### Property Example: latex


```doenet-editor-horiz
<md name="eqBlock">
  <mrow>\frac{x}{2} &= 4</mrow>
  <mrow>x + \sqrt{y} &= 3</mrow>
</md>
<p><c>latex</c> = $eqBlock.latex</p>      
```



The `latex` property returns the LaTeX code for rendering the equation block.



---

### Property Example: text


```doenet-editor-horiz
<md name="eqBlock">
  <mrow>\frac{x}{2} &= 4</mrow>
  <mrow>x + \sqrt{y} &= 3</mrow>
</md>

<p><c>text</c> = $eqBlock.text</p>  
```



The `text` property returns the text value of the equation block.
