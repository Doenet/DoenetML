# `<abs>{:dn}`

<ComponentDisplay name='abs'/>

{/*
  Introduction: say what kind of component this is, what it needs, and what it
  produces. Link related components with `[`<tag>{:dn}`](slug)`. Write for
  authors: describe what they can observe, not how it is implemented.
*/}

`<abs>{:dn}` is a [Math Operator](../concepts/essentialConcepts#component-types) component
that computes the absolute value of the math it encloses. Like [`<math>{:dn}`](math),
it can be used inline in text, inside [`<m>{:dn}`](m), or in a [`<graph>{:dn}`](graph).

### Example: Absolute value of a number

```doenet-editor-horiz
<p><m>|5 - 8| = <abs>5 - 8</abs></m></p>
```

When the enclosed expression is a number, `<abs>{:dn}` displays the numerical result.

---

### Example: Absolute value of an input

```doenet-editor-horiz
<p><mathInput name="userN"><label>Type any number or expression</label></mathInput></p>
<p><m>|$userN| = <abs>$userN</abs></m></p>
```

The enclosed math can be a reference. When it contains a variable, as in $x - 8$, the result keeps the absolute value bars.

---

### Example: Absolute value of a function

```doenet-editor
<setup>
    <function name="f">(1/4)x^2 - 4</function>
</setup>
<graph size="small">
    <shortDescription>A parabola that dips below the x-axis, and its absolute value, which is reflected above the axis</shortDescription>
    $f
    <function styleNumber="2"><abs>$f</abs></function>
</graph>
```

Wrapping `<abs>{:dn}` in a [`<function>{:dn}`](function) gives the absolute value of a function. The parts of $f$ below the $x$-axis are reflected above it.

---

### Attribute Example: displayDigits

```doenet-editor-horiz
<p>Default: <abs>-pi</abs></p>
<p>With <c>displayDigits="6"</c>: <abs displayDigits="6">-pi</abs></p>
```

`displayDigits` sets how many significant digits are shown. It changes only the display: the value used in later computations is unrounded.

---

### Property Example: number

```doenet-editor-horiz
<p><mathInput name="input" prefill="-2"><label>Enter a number or an expression</label></mathInput></p>
<p><abs name="result">$input</abs> as a number: $result.number</p>
```

The `number` property is the absolute value as a number. It is `NaN` when the result is not a number, for example when the input contains a variable.
