# `<sideBySide>{:dn}`


<ComponentDisplay name='sideBySide'/>

`<sideBySide>{:dn}` is a [Sectional](../concepts/essentialConcepts#component-types) 
component that takes enclosed sectional components and renders them in a side-by-side horizontal format.

<AttrPropDisplay name='sideBySide'/>


## Examples

### Example: Default `<sideBySide>{:dn}`


```doenet-example
<sideBySide> 
  <ul>
    <li>red</li>
    <li>orange</li>
    <li>yellow</li>
  </ul>
  <p><lorem generateWords="10"/></p>
</sideBySide>
<hr/>

<sideBySide> 
  <p><lorem generateWords="50"/></p>
  <p><lorem generateWords="100"/></p>
</sideBySide>
<hr/>

<sideBySide> 
  <graph><shortDescription>example graph</shortDescription></graph>
  <graph><shortDescription>example graph</shortDescription></graph>
  <graph><shortDescription>example graph</shortDescription></graph>
</sideBySide>
```



Three examples of different components placed in a `<sideBySide>{:dn}` are illustrated. By default, portions are assigned an equal percentage width, with no margin. These settings can be modified with the `widths` and `margins` attributes.


### On a narrow screen

When the document is narrower than 30em (480 pixels at the default text size, as on a
phone held upright), the panels of a `<sideBySide>{:dn}` are shown one below another
instead, in the order they are written, each at the full width of the document; `widths`
and `margins` apply again once the document is wide enough. The 30em grows with the
reader's text size, so a reader who enlarges the text gets the stacked layout sooner.
A `<sideBySide>{:dn}` with a single panel keeps its `widths` and `margins` at every width.
Text that refers to a panel by its position, such as "the graph on the right", does not
hold on a phone; refer to it by name instead.



## Attribute Examples

### Attribute Example: widths


```doenet-example
<sideBySide widths="20% 80%">
  <graph><shortDescription>example graph</shortDescription></graph>
  <graph><shortDescription>example graph</shortDescription></graph>
</sideBySide>
```



The `widths` attribute assigns a width to each side-by-side portion by percent.



---

### Attribute Example: margins


```doenet-example
<sideBySide widths="20% 40% 40%" margins="2%">
  <graph><shortDescription>example graph</shortDescription></graph>
  <graph><shortDescription>example graph</shortDescription></graph>
  <graph><shortDescription>example graph</shortDescription></graph>
</sideBySide>      
```



The `margins` attribute assigns a margin between each side-by-side portion by 
percent. When `widths` and `margins` attributes are both applied, margins are applied first.
