# `<ref>{:dn}`

<ComponentDisplay name='ref'/>

The `<ref>{:dn}` component renders a link to another Doenet document or to an external website.

<AttrPropDisplay name='ref'/>

## Examples

### Example: `<ref>{:dn}` to an external website


```doenet-editor-horiz
<p>For more information, see this
  <ref to="https://en.wikipedia.org/wiki/Pythagorean_theorem">
    article on the Pythagorean Theorem
  </ref>
</p>
```



In the example above, the `to` attribute of the `<ref>{:dn}` component is used with the address of an external 
webpage to create a link within a paragraph.


### Example: `<ref>{:dn}` to a figure


```doenet-editor-horiz
<figure name="temple">
  <image size="small" source="https://upload.wikimedia.org/wikipedia/commons/1/16/DoricParthenon.jpg">
    <shortDescription>A Doric column capital</shortDescription>
  </image>
  <caption>The Doric order</caption>
</figure>

<p>The capital in <ref to="$temple" /> has no ornament.</p>
```



A `<ref>{:dn}` with no link text of its own names what it points to: a
section or a titled table by its title, a numbered equation by its number in
parentheses, and a figure or an untitled table by its name, such as
"Figure 1".


## Attribute Examples

### Attribute Example: createButton


```doenet-editor-horiz
<p>For more information, see this article on
  <ref to="https://en.wikipedia.org/wiki/Pythagorean_theorem"
    createButton>
      The Pythagorean Theorem
  </ref>
</p>
```



The `createButton` attribute is used render the link in button format.
