# `<group>{:dn}`

<ComponentDisplay name='group'/>

`<group>{:dn}` is a [General Operator](../concepts/essentialConcepts#component-types)
component that collects individual DoenetML components into a single named element.

<AttrPropDisplay name='group'/>


## Examples

### Example: Grouping points for graphing


```doenet-editor-horiz

<group name="points">
  <point>(-4,1)</point>
  <point>(-1,7)</point>
  <point>(5,4)</point>
  <point>(3,-5)</point>
</group>
<polygon 
  name="polygon1" 
  vertices="$points" 
  styleNumber="5"
/>

<graph><shortDescription>A graph of a polygon</shortDescription>
  $points
  $polygon1
</graph>

<p>The group <c>points</c> contains: $points.</p>
```



A `<group>{:dn}` of `<point>{:dn}` components is defined in a `<setup>{:dn}` block. 
All of the points can then be rendered on a `<graph>{:dn}` at once using a 
single reference to the name of the `<group>{:dn}`, `$points`.

### Example: A `<group>{:dn}` of different components


```doenet-editor-horiz
<booleanInput name="hideGroup1">
  <label>Hide group 1</label>
</booleanInput>

<graph name="graph1" size="small">
  <shortDescription>A graph of different components</shortDescription>
  <group name="group1" hide="$hideGroup1">
    <line styleNumber="2">y = 2x + 3</line>
    <point styleNumber="2">(6,6)</point>
    <rectangle 
      vertices="(-4,-2) (3,2)" 
      styleNumber="2"/>
  </group>
  <circle radius="6"/>
  <line>y = -x</line>
</graph>
```



A `<group>{:dn}` need not be composed of a single type of element. 
Objects defined within a `<group>{:dn}` can be collectively hidden.

A property after a `<group>{:dn}` that holds several components, such as
`$group1.x`, can't tell which one you mean, so it names nothing: give the
component a name and write the name before the property. A `<group>{:dn}`
holding one component stands for it, so a property after it is that
component's. A `<group>{:dn}` holding only a reference to a `<repeat>{:dn}`
stands for the `<repeat>{:dn}`, so a property after it is the
`<repeat>{:dn}`'s own, such as `numItems`, as after the `<repeat>{:dn}`
itself. A `<group>{:dn}` holding only a list stands for the list, so a name
written in the list names that component after the group too: with
`<point name="P">{:dn}` written in a `<pointList name="pl">{:dn}`, `$g.P` of
`<group name="g">$pl</group>{:dn}` is that point, as `$pl.P` is.

A `<group>{:dn}` made with `extend` from a `<repeat>{:dn}` holds its
iterations, followed by anything written in the `<group>{:dn}`, and follows
the number of iterations as it changes:
`<group extend="$r"><text>end</text></group>{:dn}`. With no iterations, it
holds just what is written in it. An attribute written on it, such as
`hide`, is the `<group>{:dn}`'s, not each iteration's.
