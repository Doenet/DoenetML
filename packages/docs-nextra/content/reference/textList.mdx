# `<textList>{:dn}`

<ComponentDisplay name='textList'/>

The `<textList>{:dn}` is a [Text](../concepts/essentialConcepts#component-types)
component that stores a list of texts, each like a [`<text>{:dn}`](text.mdx).

When creating a `<textList>{:dn}`, separate items by **commas** or by
**spaces**, as for any [list](../concepts/essentialConcepts#lists): if the text has a comma outside brackets,
commas separate the entries, and otherwise spaces do. So
`<textList>hello world, goodbye</textList>{:dn}` is the two texts
`hello world` and `goodbye`. An entry that needs a comma, or a space in a
list separated by spaces, is written as a `<text>{:dn}` child.
The component will default to displaying the list with commas.

<AttrPropDisplay name='textList'/>

## Examples

### Example: `<textList>{:dn}` with direct input


```doenet-editor-horiz
<p>A list of flower names: 
 <textList name="flowerNames">
    rose lily daffodil tulip
  </textList>
</p>
```



In the sample code above, the individual texts are listed directly between the opening and closing `<textList>{:dn}` tags, with spaces to separate list items. Commas would separate them too.



---

### Example: `<textList>{:dn}` from user-input


```doenet-editor-horiz
<p>Name 3 reptiles:</p>
<ol>
  <li>
    <textInput name="r1">
      <shortDescription>reptile 1</shortDescription>
    </textInput>
  </li>
  <li>
    <textInput name="r2">
      <shortDescription>reptile 2</shortDescription>
    </textInput>
  </li>
  <li>
    <textInput name="r3">
      <shortDescription>reptile 3</shortDescription>
    </textInput>
  </li>
</ol>

<p>Your list of reptiles is: 
  <textList name="reptileList">
    $r1 $r2 $r3
  </textList>
</p>

<p>The third item in the list is a $reptileList[3]</p>
```



The user is prompted to provide three text responses 
with the `<textInput/>{:dn}` component, which are then referenced within the 
definition of a `<textList>{:dn}`. Individual entries in the list can be referenced by index.



## Attribute Examples

### Attribute Example: unordered


```doenet-editor-horiz
<p>Enter "apple", "banana", "orange":</p>
<ul>
  <li>
    <textInput name="fruit1">
      <shortDescription>fruit 1</shortDescription>
    </textInput>
  </li>
  <li>
    <textInput name="fruit2">
      <shortDescription>fruit 2</shortDescription>
    </textInput>
  </li>
  <li>
    <textInput name="fruit3">
      <shortDescription>fruit 3</shortDescription>
    </textInput>
  </li>
</ul>

<textList name="userAns" unordered hide>
  $fruit1 $fruit2 $fruit3
</textList>

<answer>
  <award>
    <when>
      $userAns = $answerList
    </when>
  </award>
</answer>
<boolean>$userAns = $answerList</boolean>

<p>Answers = 
  <textList name="answerList">
    orange banana apple
  </textList>
</p>
```



The `unordered` attribute allows for boolean comparisons between lists, 
such as in the `<award>{:dn}` component or the `<boolean>{:dn}` component,
without regard to the order in which the names of the fruits have been entered.


---

### Attribute Example: maxNumber


```doenet-editor-horiz
<p>A list of dog breeds: 
  <textList name="dogBreeds" maxNumber="3">
    poodle chihuahua bulldog husky dobermann
  </textList>
</p>
```



In the sample code above, the maximum number of texts displayed is 3, even 
though there are 5 texts listed directly between the opening and closing `<textList>{:dn}` tags.
