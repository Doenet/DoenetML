# `<collect>{:dn}`

<ComponentDisplay name='collect'/>

`<collect>{:dn}` is a [General Operator](../concepts/essentialConcepts#component-types)
component that gathers discrete component data from a graph or 
sectional component and stores it in an array.

<AttrPropDisplay name='collect'/>


## Examples

### Example: Collect `<point>{:dn}` children from a `<graph>{:dn}`


```doenet-editor-horiz
<graph name="g" size="small">
  <shortDescription>A graph of three points</shortDescription>
  <point>(-8,-8)</point>
  <point>(-3,5)</point>
  <point>(6, 3)</point>
</graph>

<collect 
  name="collectPoints" 
  from="$g" 
  componentType="point"/>

<graph size="small">
  <shortDescription>A graph showing the collected points</shortDescription>
  $collectPoints
</graph>
```



The `<collect/>{:dn}` component is used to gather `<point>{:dn}` 
children from a named `<graph>{:dn}`.



---

### Example: Collect `<textInput>{:dn}` children from a `<repeat>{:dn}`


```doenet-editor-horiz
<p>
  <mathInput name="n"><label>How many words do you know?</label></mathInput>
</p>

<p>The words I know are:</p>
<repeatForSequence name="wordRepeat" from="1" to="$n">
  <textInput><shortDescription>A word you know</shortDescription></textInput>
</repeatForSequence>

<p>The collected <tag>textInput</tag> children: 
  <collect 
    name="collectWords" 
    from="$wordRepeat" 
    componentType="textInput"/>
</p>

<p>You know the words: 
  <repeat for="$collectWords" valueName="word">$word.value</repeat>
</p>
```




The `<collect/>{:dn}` component is used to gather `<textInput>{:dn}` 
components generated by a `<repeat>{:dn}`. A `<repeat>{:dn}` over the
`<collect>{:dn}` reads the value of each one; a property right after the
`<collect>{:dn}`, such as `$collectWords.value`, would be the
`<collect>{:dn}`'s own, and names nothing.



---

### Example: Collect user-added `<point>{:dn}` children to draw a `<polygon>{:dn}`


```doenet-editor-horiz
<graph name="g" xMin="-1" yMin="-1">
  <shortDescription>A graph with user-added points forming a polygon</shortDescription>
  <callAction 
    actionName="addChildren" 
    target="$g" 
    anchor="(8,1)">
      <point>
        (9* <sampleRandomNumbers/>,
        9* <sampleRandomNumbers/>)
      </point>
      <label>Add point</label>
  </callAction>

  <polygon 
    vertices="$collectPoints" 
    filled 
    styleNumber="3"/>
</graph>

<collect 
  name="collectPoints" 
  componentType="point" 
  from="$g"/>
```



The `<collect/>{:dn}` component is used to gather `<point>{:dn}` 
components generated by two `<callAction>{:dn}` components 
within a `<graph>{:dn}`. The named `<collect/>{:dn}` is then referenced 
in the `vertices` attribute of a `<polygon>{:dn}`.


---

### Example: `<collect>{:dn}` function data

```doenet-editor-horiz
<setup>
  <collect 
    name="quadraticFunctions" 
    componentType="function" 
    from="$defineQuadratics"/>
</setup>

<subsection name="defineQuadratics" hide="true">
  <function name="f">x^2 - 2</function>
  <function name="g">-(x^2)/2+4</function>
  <function name="h">(x^2)/3-1</function>
</subsection>

<p>The collected functions are: 
  <m>\{f(x),g(x),h(x)\} =   
  \{</m>$quadraticFunctions<m>\}</m>
</p>

<graph>
  <shortDescription>A graph of three collected quadratic functions</shortDescription>
  $quadraticFunctions
</graph>
```

The `<collect>{:dn}` can be used for `function{:dn}` components as well 
as graphical components and that the set of data collected need not 
be contained in a `graph{:dn}`.  Any sectional component or module can 
be used with the `from` attribute inside the `<collect>{:dn}` component.

---


### Example: Collecting a property of a component


```doenet-editor-horiz
<graph name="g" size="small">
  <shortDescription>A graph of three circles with different radii</shortDescription>
  <circle />
  <circle radius="3/2"/>
  <circle radius="3"/>
</graph>

<collect 
  name="collectRadii" 
  componentType="circle" 
  from="$g"/>


<p>The collected radii are:
<repeat for="$collectRadii" valueName="c">$c.radius</repeat></p>

<p>The second radius is: 
  $collectRadii[2].radius</p>
```

To read a property of every collected component, use a
`<repeat>{:dn}` over the `<collect>{:dn}`, as for the radii here. A property
right after the `<collect>{:dn}`, such as `$collectRadii.radius`, is the
`<collect>{:dn}`'s own, and names nothing.

To access a specific component's property,
use the index of the component in square brackets, 
such as `$collectRadii[2].radius`.

## Attribute Examples

### Attribute Example: from


```doenet-example
<graph name="g" size="small">
  <shortDescription>A graph with a callAction button to add points</shortDescription>
  <callAction 
    actionName="addChildren" 
    target="$g" 
    anchor="(-6,-8)">
      <point>(0,0)</point>
      <label>Add point</label>
  </callAction>
</graph>
<collect componentType="point" from="$g"/>
```



The `from` attribute specifies which named component the `<collect>{:dn}` 
is gathering information from.



---

### Attribute Example: componentType


```doenet-example
<p>repeated mathInputs:</p>

<repeatForSequence name="blanksRepeat" from="1" to="3">
  <mathInput><shortDescription>example input</shortDescription></mathInput>
</repeatForSequence>

<p>The collected mathInputs are:</p>
<collect 
  name="collectMathInputs"
  componentType="mathInput" 
  from="$blanksRepeat"/>

<p>The third <tage>mathInput</tage> is:</p>
  $collectMathInputs[3]
```



The `componentType` attribute specifies the type of component 
that is being collected from the reference listed in `from`.
Write it as you would write the tag, in the same case: `componentType="mathInput"`,
not `componentType="MathInput"`.


---

### Attribute Example: maxNumber


```doenet-editor-horiz
<p>
  <mathInput name="n"><label>Number of points to repeat (type a number <m> > 3</m>)</label></mathInput>
</p>

<graph name="g" size="small">
  <shortDescription>A graph of random points</shortDescription>
  <repeatForSequence from="1" to="$n">
    <point>
        (<selectFromSequence from="-9" to="9"/>,
        <selectFromSequence from="-9" to="9"/>)
      </point>
  </repeatForSequence>
</graph>

<p>The first three points are: 
  <collect 
    name="collectPoints" 
    componentType="point" 
    from="$g" 
    maxNumber="3"/>
</p>
```

The `maxNumber` attribute sets a limit on the number of components to collect.
With no `maxNumber`, there is no limit. Like every attribute of a
`<collect>{:dn}`, it is not a property: `$collectPoints.maxNumber` names
nothing, with a warning. Read how many were collected with `numItems`.


---

## Property Examples

### Property Example: numItems


```doenet-editor-horiz
<graph name="g">
  <shortDescription>A graph of three points</shortDescription>
  <point>(1,2)</point>
  <point>(3,4)</point>
  <point>(-2,1)</point>
</graph>
<collect name="c" componentType="point" from="$g"/>
<p>Number of points collected: $c.numItems</p>
<p>The x-coordinate of the second: $c[2].x</p>
```

`numItems` is the number of components collected, which an index selects
among (`$c[2]` is the second). A property or a name after the
`<collect>{:dn}` is the `<collect>{:dn}`'s own, never each component's: `$c.x`
names nothing, with a warning suggesting an index, as above.
