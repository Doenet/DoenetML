# `<argMax>{:dn}`

<ComponentDisplay name='argMax'/>

`<argMax>{:dn}` is a [General Operator](../concepts/essentialConcepts#component-types)
component that renders the **index** of the largest of its arguments, rather than the
value itself. Indices start at 1, ties resolve to the first occurrence, and an empty
list gives 0.

Because DoenetML lists can be indexed by a reference, the index that `<argMax>{:dn}`
produces can be used to look up the matching entry of a *different* list — which is
what makes it more useful than [`<max>{:dn}`](max) alone.

Values are compared numerically when they are all numeric, and alphabetically
otherwise, exactly as in [`<sort>{:dn}`](sort).

<AttrPropDisplay name='argMax'/>

## Examples

### Example: the position of the largest value


```doenet-editor-horiz
<numberList name="nl">3 1 4 1 5 9 2 6</numberList>

<p>Values: $nl</p>
<p>Largest value: <max>$nl</max></p>
<p>Position of the largest value: <argMax>$nl</argMax></p>
```



---

### Example: who scored highest


```doenet-editor-horiz
<setup>
  <textList name="names">Ann Bob Cal Dee</textList>
  <numberList name="scores">72 91 65 88</numberList>
</setup>

<argMax name="best">$scores</argMax>

<p>Scores: $scores</p>
<p>The highest score was earned by $names[$best].</p>
```



The index from `<argMax>{:dn}` indexes into the parallel list of names.



---

### Example: responding to user input


```doenet-editor-horiz
<p><mathInput name="a" prefill="4"><label>first value</label></mathInput>
   <mathInput name="b" prefill="9"><label>second value</label></mathInput>
   <mathInput name="c" prefill="2"><label>third value</label></mathInput></p>

<argMax name="which">$a $b $c</argMax>

<p>The largest is the number in box $which.</p>
```



The index updates as the values change.
