# `<sampleRandomNumbers/>{:dn}`


<ComponentDisplay name='sampleRandomNumbers'/>

`<sampleRandomNumbers/>{:dn}` is a [Math](../concepts/essentialConcepts#component-types) 
component that generates random numbers from a specified range of values, from a normal distribution 
around a specified mean, or from one of the discrete count distributions (hypergeometric, binomial, 
and Poisson). It differs from the `<selectRandomNumbers/>{:dn}` component in that the 
values can be altered within the document by resampling or changing one or more of the 
component's attributes. The primary application of the `<sampleRandomNumbers/>{:dn}` component 
is for use in simulations involving random numbers.


<AttrPropDisplay name='sampleRandomNumbers'/>


## Examples

### Example: Default `<sampleRandomNumbers/>{:dn}`


```doenet-editor-horiz

<sampleRandomNumbers name="sample" />

<p>Number selected = $sample</p>
```



Without any attributes specified, the default sampling `type` is `uniform`, and the 
default interval is $[0, 1)$. In this example, there are two ways to view different 
samples: selecting another variant, or refreshing the page.



---

### Example: Using a re-sampling button


```doenet-editor-horiz
<p><sampleRandomNumbers name="randomNumber"/></p>

<callAction actionName="resample" target="$randomNumber">
  <label>Get a New Number</label>
</callAction>
```



Without any attributes specified, the default sampling `type` is `uniform`, and 
the default interval is $[0, 1)$. The `<callAction>{:dn}` button can be used to 
resample the value.



## Attribute Examples

### Attribute Example: numSamples



The `<sampleRandomNumbers/>{:dn}` component is used with the `numSamples` attribute to 
select multiple random values in the default interval $[0,1)$. The default `type` is `uniform`.

### Attribute Example: type = "hypergeometric"


```doenet-example
<p>An urn holds 20 marbles, 7 of which are red. 
  Draw 5 marbles without replacement and count the red ones, 
  repeated 10 times:
  <sampleRandomNumbers 
    name="x" 
    type="hypergeometric" 
    numTotal="20" 
    numSuccesses="7" 
    numDraws="5" 
    numSamples="10"
  />
</p>

<callAction actionName="resample" target="$x">
  <label>Get New Numbers</label>
</callAction>

<p>Expected number of red marbles in each set of 5 draws: $x.mean</p>
```



The `hypergeometric` type counts the successes obtained when drawing `numDraws` 
items *without replacement* from a population of `numTotal` items containing 
`numSuccesses` successes. Because the draws within a single sample deplete the 
population, this is the without-replacement counterpart of the `binomial` type.

Each sample lies between $\max(0, n - (N - K))$ and $\min(n, K)$, where 
$N$ is `numTotal`, $K$ is `numSuccesses`, and $n$ is `numDraws`.

Unlike the other distributions, `hypergeometric` has no defaults to fall back on. 
If any of the three attributes is omitted, or they do not describe a population 
(for example, more successes or more draws than there are items), every sample is 
`NaN`, as are the reported `mean`, `variance`, and `standardDeviation`.

The three discrete distributions &mdash; `hypergeometric`, `binomial`, and `poisson` 
&mdash; draw their samples one item, trial, or event at a time, so very large 
parameters would take a long time and leave the page unresponsive while they ran. 
Parameters that would need more than ten million draws for a single sample are 
therefore treated as unusable, giving `NaN` samples and statistics along with a 
warning explaining what to change. The limit is far above the populations, trial 
counts, and rates that arise in practice; it is there so that mistyping an extra 
digit reports a problem instead of freezing the activity. An order of magnitude 
below that, from a million draws per sample, the samples are still drawn as asked, 
but a warning notes that sampling may be slow. Note that both figures apply to 
each sample individually &mdash; a large `numSamples` still takes proportionally 
longer.

### Attribute Example: type = "binomial"


```doenet-example
<p>Flip a biased coin 10 times and count the heads, repeated 10 times:
  <sampleRandomNumbers 
    name="x" 
    type="binomial" 
    numTrials="10" 
    probability="0.3" 
    numSamples="10"
  />
</p>

<callAction actionName="resample" target="$x">
  <label>Get New Numbers</label>
</callAction>

<p>Expected number of heads per sample: $x.mean</p>
```



The `binomial` type counts the successes in `numTrials` independent trials that 
each succeed with the given `probability`. If unspecified, `numTrials` is 1 and 
`probability` is 0.5, so `type="binomial"` on its own produces a fair coin flip 
reported as 0 or 1.



---

### Attribute Example: type = "poisson"


```doenet-example
<p>Number of calls arriving each hour, averaging 4 per hour:
  <sampleRandomNumbers 
    name="x" 
    type="poisson" 
    mean="4" 
    numSamples="10"
  />
</p>

<callAction actionName="resample" target="$x">
  <label>Get New Numbers</label>
</callAction>

<p>Variance of the distribution: $x.variance</p>
```



The `poisson` type is determined entirely by its `mean`, which also equals its 
variance. Unlike the `gaussian` type, whose `mean` defaults to 0, the `mean` of a 
`poisson` distribution defaults to 1, since a Poisson distribution with mean 0 
always returns 0.
