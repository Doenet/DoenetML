# `<m>{:dn}`

<ComponentDisplay name='m'/>

`<m>{:dn}` is a [Display Math](../concepts/essentialConcepts#component-types)
component that renders inline mathematical content.  The `<m>{:dn}` tag accepts Latex and 
DoenetML mathematical content as input.

For displaying mathematics alone on a line by itself, see `<me>{:dn}`, `<men>{:dn}` 
or `<md>{:dn}`,`<mdn>{:dn}` (for aligned mathematics). See also `<math>{:dn}`
for mathematical manipulations using a computer algebra system.

<AttrPropDisplay name='m'/>

## Examples

### Example: `<m>{:dn}` inside a paragraph


```doenet-editor-horiz
<p>In this example, <m>F=5.27</m> <m>kN</m> applied in the <m>y</m> direction.</p>
```



The `<m>{:dn}` component is used to format isolated content within a section of 
text that has been enclosed within a `<p>{:dn}`, or paragraph component. 



---

### Example: `<m>{:dn}` in combination with `<math>{:dn}`


```doenet-editor-horiz
<math name="expr">x^2 + y^2</math>
<p><m>f(x,y) = $expr</m></p>
```



An `<m>{:dn}` tag encloses an inline math expression that also contains a 
reference to a named `<math>{:dn}`.



---

### Example: `<m>{:dn}` in combination with <tage>mathInput</tage>


```doenet-editor-horiz
<p><mathInput name="mi"><label>Enter a function in <m>x</m></label></mathInput></p>
<p><m>f(x) = $mi</m></p>
```



An `<m>{:dn}` tag encloses an inline math expression that also contains a 
reference to a named `<mathInput/>{:dn}`. The reference shows what the reader
has entered; the input itself stays where it is written, above the expression.
To put the input *into* the expression instead, write it there — see the next
example.



---

### Example: an input inside `<m>{:dn}`


```doenet-editor-horiz
<p><m>x = <textInput name="ti" /> + 3</m></p>
<p>You entered: <text extend="$ti" /></p>
```


A `<textInput/>{:dn}`, a `<mathInput/>{:dn}`, or an inline
`<choiceInput/>{:dn}` written inside an `<m>{:dn}` is rendered *in place*,
inside the typeset expression, so the reader fills in the blank where it
belongs rather than beside the mathematics. Use a `<mathInput/>{:dn}` when the
answer is mathematics the reader should write as mathematics — a fraction, a
root, an exponent — and a `<textInput/>{:dn}` when a line of ordinary text will
do. The expression makes room as a `<mathInput/>{:dn}` grows, and settles once
the reader presses Enter or moves on.

Without a `<shortDescription>{:dn}`, the input is described to a screen reader
by the expression it sits in — the example above reads as "x equals blank plus
3" — and a visible `<label>{:dn}` is not drawn, since there is nowhere inside
an equation to put one.

Write a `<shortDescription>{:dn}` when the expression does not read as a
sentence with the blank in it. Two cases where it will not: when the input sits
somewhere that reading left to right loses, such as a subscript, a superscript,
a fraction, or a root; and when an expression holds so many blanks that a
reader is left counting which one they are on. Where the expression does read
plainly, as `x = <textInput/> + 3` does, it names the input better than a
description would, and none is needed.

Not every input can be placed inside an expression. A non-`inline`
`<choiceInput/>{:dn}` or an `expanded` `<textInput/>{:dn}` is too large to sit
in a line of mathematics, a `<textInput/>{:dn}` needs a `width` given in
absolute units such as `px` rather than `%` or `em`, and mathematics drawn on a
`<graph>{:dn}` has no room for an input. Those are still accepted, but they are
not drawn inside the expression, and they warn to say so.



---

### Example: a `<mathInput/>{:dn}` inside `<m>{:dn}`


```doenet-editor-horiz
<p><m>\int_0^1 x^2 \, dx = <mathInput name="area">
  <shortDescription>the value of the integral</shortDescription>
</mathInput></m></p>
<p>You entered: <m>$area</m></p>
```


The reader writes their answer as mathematics, in the place the answer belongs.
The expression makes room as the answer grows, and closes back up around it
once the reader presses Enter or moves on.



---

### Example: `<m>{:dn}` in combination with `<answer>{:dn}`


```doenet-editor-horiz
<p><answer symbolicEquality><label>Simplify <m>x \cdot x = </m></label>x^2</answer></p>    
```



An `<m>{:dn}` tag encloses an inline math expression that precedes 
an `<answer>{:dn}`. Note that an `<answer>{:dn}` cannot be *defined* within 
an `<m>{:dn}` component.
